# 🤖 Autonomous Accessibility Analysis 

Autonomous accessibility analysis in public buildings using a self-designed robotic system.  \
Implemented in C++, featuring a **custom-developed area-scanning and navigation algorithm**, built from scratch to maximize scanning efficiency.  \
Designed to support future integration of **machine-learning–based object detection**.  \
The system aims to **assist enforcement authorities in evaluating accessibility compliance**, ultimately supporting people with disabilities.

This final-year project demonstrates how robotics and autonomous software can help **identify accessibility issues efficiently**, providing practical tools to enforce accessibility regulations and improve access for individuals with disabilities.

## 🛠 Features and Technologies
- Autonomous scanning of public building spaces using **custom-developed space scanning and navigation algorithm**
- Prototype demonstrates a practical application for autonomous navigation in a real-world context. And brings a final result of the level of accessibility of the building for people with pedestrian, hearing and visual disabilities.
- Written in C++
- Future combination of **computer vision-based object recognition and machine learning** for automatic recognition of elements in space.
